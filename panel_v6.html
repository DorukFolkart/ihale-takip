SAP Entegrasyonu — Hazırlık
🧩
Hazırlık Aşaması
SAP bağlantısı için veri kaynağı katmanı (DataSource) hazırlandı. Bağlantı bilgileri girilip aktif edildiğinde panel verileri SAP'tan çekebilecek. Şu an veri kaynağı: Supabase.
SAP Bağlantı Ayarları
Eşleştirme Planı (SAP → Panel)
SAP Proje (PSP) → proje
WBS / Aktivite → takvim_no / paket
Milestone tarihleri → M1–M8 planlanan/gerçekleşen
Satınalma talebi (PR) → M3 Talep
Satınalma siparişi (PO) → M7 Sözleşme
Sözleşme tutarı → sözleşme_bedeli
Not: Gerçek bağlantı IT tarafından SAP servis uçları sağlandığında DataSource._sapIhaleleriGetir() içinde tamamlanacak.
